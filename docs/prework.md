# Before You Arrive

You do **not** need to log in to the Yens, install anything, or read anything before Day 1.
We start from scratch in the room.

---

## 1 — A GitHub account

[github.com/signup](https://github.com/signup) — free. If you already have one, use it;
there is nothing to change.

That is all we need. We create the access token you'll push with **in class** on Day 1,
because it only takes two minutes and it is easier to do together.

## 2 — Claude, through Stanford

[uit.stanford.edu/service/claude](https://uit.stanford.edu/service/claude) — Stanford
provides **Claude for Education** free to most people, and we use it on both days.

{: .warning }
> **Request this now, not the night before.** Approval goes through ServiceNow and is not
> instant. It is the one item on this page with someone else in the loop.

---

## A Note on Yens Access {#what-depends-on-what}

You do not need to *use* the Yens before class — but your account does need to **exist** by
Day 1, and that part can take days: it may involve faculty sponsorship, a SUNet ID, or
being added to a workgroup.

Faculty, PhD students, post-docs, and research fellows have access **by default** — if that
is you, there is nothing to do. If you are not sure, check
[Access the Yens](https://rcpedia.stanford.edu/_getting_started/how_access_yens/) now
rather than on the morning.

### If something is missing when you arrive

| Missing | What happens on the day |
|---|---|
| **Yens access** | This is the one we can't fix in the room. Tell us at 9:00 and we'll pair you with someone for the day — you'll get every concept and can redo the hands-on work that evening |
| **Claude account** | Everything except Claude Code itself works without it. We'll pair you up |
| **GitHub account** | Two minutes in a browser. Just say so at 9:00 |

Nothing else is assumed. If you have never used a command line, that is fine — say so and
we'll seat you next to someone who has.
